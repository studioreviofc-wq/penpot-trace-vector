# Trace Vector — Penpot plugin

Turn images into editable vectors (SVG) inside Penpot: logos, icons and illustrations, in color or black and white, with live preview.

**Install in Penpot:** Plugins → paste `https://studioreviofc-wq.github.io/penpot-trace-vector/manifest.json`

- 6 styles: Logo, Illustration, Photo, Black & white, Drawing, Pixel art
- Colors, speck cleanup, smoothness, corners, solid background removal
- Live preview with original/vector comparison, shape and color count
- Place next to the image or on top, download or copy SVG
- Runs 100% in the browser — images never leave your computer
- English, Português, Español

Made by Studio REVI. Tracing engine: [VTracer](https://github.com/visioncortex/vtracer) by visioncortex (MIT OR Apache-2.0), see `docs/LICENSE-vtracer.txt`.
